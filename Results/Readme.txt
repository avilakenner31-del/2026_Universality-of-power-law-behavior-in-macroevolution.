# Original MCMC Posterior Output Files (Paper Results)

This directory contains the original Markov Chain Monte Carlo (MCMC) posterior distribution output files generated by the `.f95` modeling suite and used for the analysis, figures, and statistical cuts presented in the original paper.

## 1. Directory Inventory

* **`posteriorDino.txt`** — MCMC results mapping the primary full dataset (from `ListaGrado1.txt`).
* **`posteriorDinoO.txt`** — MCMC results mapping the subset variation (from `ListaGrado2_o.txt`).
* **`posteriorDinoS.txt`** — MCMC results mapping the subset variation (from `ListaGrado2_s.txt`).
* **`posteriorDinoT.txt`** — MCMC results mapping the subset variation (from `ListaGrado2_t.txt`).

---

## 2. Execution Context & Filtering (Burn-in)

The files contained in this folder do **not** represent the raw, unedited 100,000 steps of the MCMC simulation. To eliminate initialization bias, a burn-in constraint was applied directly during runtime:
* **Condition:** Only steps satisfying `20 * i > 100,000` (equivalent to skipping the first 5,000 structural exploration steps) were committed to these data logs.
* **Header Structure:** The first line of each file contains a blank buffer row introduced by the program (`write(101,*)""`), followed by the structural parameter entries.

---

## 3. Data Format & Column Definitions

All files are structured as space-separated tabular text files consisting of exactly 4 columns. Values in Column 4 leverage scientific notation notation (`E-xx`).

### Column Breakdown:

| Column | Program Variable | Data Type | Scientific / Statistical Definition |
| :--- | :--- | :--- | :--- |
| **1** | `M1(i)` | Real | **Normalization Constant (\(M_1\)):** Represents the scaling factor or base mass intercept in the power-law equation. |
| **2** | `Q(i)` | Real | **Power-Law Exponent (\(Q\)):** Represents the scaling exponent parameter governing the mass decay curve (\(M = M_1 \cdot x^{-Q}\)). |
| **3** | `num(i)` | Integer | **Sample Step Range (\(N_{\text{sub}}\)):** Represents the dynamically sampled effective data boundary size evaluated during that specific MCMC iteration. |
| **4** | `postNorm(i)` | Real | **Normalized Posterior Probability:** The absolute posterior likelihood density value at this parameter space coordinates, pre-divided by the normalization constant \(Z\). |

### Structural Preview Example:
```text
[Blank Row Space Buffer]
7690.97559        0.442044854                36     1.17961790E-05
7690.97559        0.442044854                36     1.17961790E-05
7681.38770        0.471083879                35     8.61404942E-07
```

*Note: Repeated lines reflect consecutive accepted state freezes within the Metropolis-Hastings random walk loop when subsequent candidates were statistically rejected.*

---

## 4. Usage for Plotting and Reproducibility

These datasets are ideal for reproducing the paper's final parameter distribution profiles:
1. **Marginalized Histograms:** Columns 1 ($M_1$) and 2 ($Q$) can be extracted independently to plot probability density functions (PDFs) or 2D contour maps of parameter correlations.
2. **Confidence Intervals:** Sorting this data by Column 4 in descending order yields the precise cumulative sum cuts corresponding to the 1-sigma (68.3%), 2-sigma (95.4%), and 3-sigma (99.7%) confidence limits reported in the text.
